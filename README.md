# НОМЕРОН / NOMERON

Казуальный коллекционный симулятор для [Яндекс Игр](https://yandex.ru/games/).
Крути барабан, **фиксируй удачные символы и перекручивай остальные**, выполняй заказы
и собирай коллекцию редких знаков вымышленного города Вектор-Сити.

Чистый JavaScript, без сборщиков и зависимостей. Разархивированный размер — **292 КБ**.

---

## Запуск локально

```bash
python3 -m http.server 8080
# открыть http://localhost:8080
```

SDK Яндекс Игр (`/sdk.js`) локально недоступен — игра это распознаёт и запускается
в офлайн-режиме: сохранения идут в `localStorage`, реклама и покупки отключены.

## Сборка архива для Консоли

```bash
./build.sh      # создаёт nomeron.zip
```

В архив попадают только `index.html`, `styles.css`, `src/` и `assets/`.
Папки `docs/` и `promo/` в игру не входят.

## Что реализовано

**Ядро.** Спин с последовательной остановкой барабанов, фиксация любого из 6 символов,
реролл незафиксированных за кредиты. Стоимость реролла — 25% от текущей оценки знака,
поэтому доводить дорогую заготовку дороже, и каждый спин превращается в решение.

**Формат знака.** Буква — три цифры — две буквы — код округа, как на привычных
российских номерах. Отличия, которые уводят от копирования: код страны **SUR**,
флаг вынесен в **левую вертикальную полосу**, триколор **белый-красный-синий**,
шрифт похожего силуэта, но других пропорций, округа вымышленные.
Буквы — 12 символов, одинаковых в кириллице и латинице (`A B E K M H O P C T Y X`).

**Редкость.** 13 паттернов (три одинаковые цифры, лестницы, зеркала, парные буквы,
низкие и круглые номера, серия округа, счастливые семёрки) складываются в Индекс 0–100
и шесть тиров. Цена растёт нелинейно: `10 × (1 + Индекс/10)^2,2`.

**Заказы.** Четыре типа требований, дедлайн в спинах, мини-игра торга. Сбалансированы
симуляцией: выполнимость ~90% при активной игре с рероллами.

**Коллекции.** 9 сетов, награда — перманентный бонус (цена продажи, шанс редкости,
рероллы, слоты). Даёт причину не продавать редкий знак.

**Мастерская.** 6 веток апгрейдов, автокрутилка с фильтром по тиру, оффлайн-доход.

**«Знак дня».** Общий для всех игроков сид, 5 попыток, 2 реролла, лидерборд недели.

**Удержание.** Ежедневные задания, серия входов на 7 дней, недельный сезон округа (×2 к цене).

| Пункт | Требование | Где реализовано |
|---|---|---|
| 1.1, 1.19.1 | SDK подключён и инициализирован по документации | `index.html`, `platform/ysdk.js` |
| 1.19.2 | `LoadingAPI.ready()` в момент готовности | `main.js` → `Platform.ready()` |
| 1.19.4 | Обработка `game_api_pause` / `game_api_resume` | `main.js` → `bindLifecycle()` |
| 1.2.1 | Авторизация только по кнопке с объяснением выгоды | `promptAuth()` |
| 1.2.2 | Гостевой режим с сохранением прогресса | `storage.js` |
| 1.3 | Звук стопается при потере фокуса | `visibilitychange`, `blur` → `Audio.suspend()` |
| 1.4, 1.13.1 | Платежи через SDK, консумирование при старте | `payments.js` → `consumePending()` |
| 1.13.2, 1.13.4 | Название, иконка и цена валюты из SDK | `openShop()` берёт данные из `getCatalog()` |
| 1.7 | Нет абсолютных URL на серверы Яндекса | проверено, только относительные пути |
| 1.9 | Сохранение сразу после действия | `State.save()` после каждого действия |
| 1.10.2 | Нет браузерной прокрутки и swipe-to-refresh | `overflow: hidden`, `overscroll-behavior: none` |
| 1.10.4 | Управление одной рукой | портретная колонка, нижняя навигация |
| 1.21 | Размер ≤ 100 МБ | 292 КБ |
| 1.22 | `index.html` в корне, ASCII-имена файлов | проверено |
| 1.23 | Нет интерактивного ИИ | графика сгенерирована заранее |
| 2.14 | Автоопределение языка | `i18n.js` ← `environment.i18n.lang` |
| 3.4.4 | Нет политики и госструктур | вымышленный Вектор-Сити |
| 4.5.2 | RV — только бонус, не условие продолжения | энергии нет, крутить можно бесконечно |
| 4.7 | Пауза звука и геймплея при рекламе | `Ads.onAdStart` / `onAdEnd` |
| 6.2 | Можно выключить звук | Настройки |
| 1.6.2.4 | Клавиатура, не зависящая от раскладки | обработка по `event.code` |

**Управление.** Мышь и касания; на клавиатуре: `Space` — крутить, `1`–`6` — фиксировать
символы, `R` — реролл, `Esc` — закрыть окно.

## Что нужно сделать в Консоли разработчика

Это действия владельца аккаунта, из репозитория их выполнить нельзя.

1. **Профиль → Единая лицензионная схема.** Если статус «Активен», инап-покупки
   включаются автоматически. Если нет — оформить договор; отправить игру на модерацию
   можно только после его заключения.
2. **Создать черновик**, заполнить обязательные поля (п.5.2), загрузить `promo/icon-512.png`
   и `promo/cover-800x470.png`. Иконка и обложка не должны быть скриншотами (п.5.6).
3. **Инап-покупки → Инапы.** Завести товары. Код раздаёт награды по подстроке в ID:

   | ID товара | Что выдаётся |
   |---|---|
   | `noads` | отключает интерстишлы |
   | `starter` | 5000 кредитов, 10 искр, +2 уровня калибровки |
   | `sparks_s` / `sparks_m` / `sparks_l` | 18 / 50 / 120 искр |
   | `credits` | 12000 кредитов |

   Список в игре подтягивается из `getCatalog()`, поэтому он всегда совпадает
   с Консолью (п.1.13.6). Если инапов нет — кнопка магазина просто скрывается.
4. **Лидерборды.** Создать таблицу с техническим именем `daily` (сортировка по убыванию),
   иначе «Знак дня» не будет отправлять результаты.
5. **Облачные сохранения.** Включить галочку в черновике (п.1.11).
6. **Платформы и ориентация:** десктоп + мобильные, портрет.

## Тестирование

```bash
node tools/balance-test.mjs # распределение редкостей, цены, кривая апгрейдов
node tools/orders-sim.mjs  # симуляция выполнимости заказов
```

Проверено: распределение тиров соответствует дизайну (обычные 71,4% → мифические 0,02%
на нулевом сплаве), «Знак дня» детерминирован, заказы выполнимы, прогресс переживает
перезагрузку, в консоли браузера нет ошибок (п.6.4).
